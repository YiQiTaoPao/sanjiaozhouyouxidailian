# 业务流程：
闭环设计，高效履约​

1.老板选择游戏类目 → 2. 挑选服务模式（指定 / 抢单 / 派单）→ 3. 完成下单 → 4. 客服分配打手（或打手抢单）→ 5. 打手接单提供服务 → 6. 打手上传完成截图 → 7. 客服审核进度 → 8. 结算打手佣金 → 9. 订单完成结单。

​工会专属通道：入驻团队邀请老板 → 专属订单分配 → 团队自主管理 → 独立结算，全程闭环。

# 技术栈：
主要基于 uniapp + ThinkPHP6 + MySQL 构建，支持多端（APP、小程序、H5、PC）同步。

# 特点：
提供了强大的用户体系、打手管理（等级、押金、佣金）、内容发布等功能，代练系统通常在此基础上添加“接单派单”和“订单管理”模块。

3. SaaS与商业授权的区别
SaaS版（租用）：按月、按季或按年支付使用费用（抽营业额流水）；数据都在服务商云端，没有所有权，只是购买使用权，功能不能二开受限。
商业版（授权）：一次性付费；源码交付部署在自己的服务器，数据都是自己的，拥有软件的永久使用权（可二开），完全自主独立运营使用。

SaaS = 你只能住，房子里的东西都是服务商的（租用即用）。

商业授权 = 你买下房子，装修都是自己的（购买即拥有）。
